# KnowledgeVault · 知识库

中文纯文字知识库的阅读测试版，复用已有知识库页面。

首条知识为「访客预约申请流程」，正文留空等待首次撰写。本版本用于验证公开网页在手机和微信中的访问情况；微信登录、共享编辑与持久化历史尚未开通。

## GitHub Pages 免费发布

`docs/` 已包含编译后的网页和 `.nojekyll`，无需安装依赖或手写构建流程。

在仓库 Settings → Pages 中选择：

- Source：Deploy from a branch
- Branch：main
- Folder：/docs
- Save

最终网址以 Pages 设置中的实际发布结果为准。必须完成中国大陆网络和微信真机测试后，才能确认符合分享需求。

`site/` 和 `render.yaml` 保留此前 Render 阅读测试的发布文件，不代表微信访问已通过。
